# Spice Junction 🍽️

A modern multi-page restaurant website created as part of a hackathon project.

## 🌐 Live Demo

https://hr-22.github.io/Spice-Junction/

---

## 📌 Features

- Responsive restaurant landing page
- Interactive menu section
- About page for restaurant information
- Careers page with job application form
- Admin page for managing applications
- Firebase integration for storing form data
- Clean multi-page navigation
- Modern UI using HTML, CSS, and JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase
